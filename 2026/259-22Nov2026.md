## AI_COMPLETE Adds Snowflake Decision (Preview)

AI_COMPLETE now supports Snowflake Decision, a model built for high-throughput classification, scoring and decision-making. It returns structured answers with probabilities and confidence values, at $0.042 per million tokens and about 1.58 ms per row.
https://docs.snowflake.com/en/release-notes/2026/other/2026-11-20-ai-complete-snowflake-decision-public-preview

## AI_EXTRACT Citations (Preview)

AI_EXTRACT can now return citations that tie each extracted value to its source: page numbers and bounding boxes for documents, and start and end offsets for text. Turn it on with `citation => TRUE`; it can be combined with extraction scores.
https://docs.snowflake.com/en/release-notes/2026/other/2026-11-18-ai-extract-citations

## Log Mode for Prompt Injection Guardrails

Cortex AI Guardrails now accept a `mode` setting in the `AI_SETTINGS` account parameter. `LOG` records likely prompt injections across CoCo, Snowflake Intelligence and Cortex Agents without blocking them, while `BLOCK` remains the default. Detections appear in `CORTEX_AI_GUARDRAILS_USAGE_HISTORY`.
https://docs.snowflake.com/en/release-notes/2026/other/2026-11-18-prompt-injection-guardrails-log-mode

## Cortex Agents: Every Way to Build and Call Them

🔹 **Cortex Agents REST API** - Create, manage and call Cortex Agent objects over REST, including generic tools with an `input_schema`.
https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-rest-api

🔹 **Cortex Agents Run API** - Run agents with streaming responses, tool results and warnings. With `background: true`, the timeout goes from 15 minutes to 6 hours and you can reconnect to the stream later.
https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-run

🔹 **Cortex Agent SDK** - An SDK for building client applications on Cortex Agents.
https://docs.snowflake.com/en/developer-guide/cortex-agent-sdk/cortex-agent-sdk

🔹 **AGENT_RUN SQL Function** - Run a Cortex Agent straight from SQL, without an agent object, by passing the model and tools in a JSON request body.
https://docs.snowflake.com/en/sql-reference/functions/agent_run-snowflake-cortex

🔹 **Snowflake-managed MCP Server** - Expose Cortex Agents and other tools to any MCP client. Every request runs as an authenticated Snowflake user under Agents rate limits.
https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-mcp

🔥 **Coding Agent (add-on)** - Put CoCo's coding abilities (bash, file edits, grep/glob, web search, SQL) into your own apps with the `code_toolset_all` tool, which runs in a Snowflake-managed sandbox. You can reach it through REST, SQL or MCP.
https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-coding-agent
