## **Snowflake Platform Updates**

### SPCS Autoscaling Policies (GA - May 4)

**Snowpark Container Services autoscaling policies** are now GA. Define metric-based rules that control how Snowflake scales service instances up, down, or suspends them automatically. Supports both platform metrics and custom metrics.

**Read more:** https://docs.snowflake.com/en/release-notes/2026/other/2026-05-04-spcs-autoscaling-policies-ga

**Documentation:** https://docs.snowflake.com/en/developer-guide/snowpark-container-services/scaling-services

### Four New SPCS Instance Families (GA - May 5)

Four new **Snowpark Container Services instance families** are GA:
- **GEN_X64_G2** (AWS, Azure) - Second-gen general-purpose compute
- **MEM_X64_G2** (AWS, Azure) - Second-gen high-memory compute
- **GPU_NV_L4_G2** - NVIDIA L4 GPU instances
- **GPU_NV_H100** - NVIDIA H100 GPU instances

**Read more:** https://docs.snowflake.com/en/release-notes/2026/other/2026-05-05-spcs-new-instance-families-ga

### SAP BDC Zerocopy Connector (GA - May 4)

The **SAP BDC Zerocopy Connector** is GA - zero-copy data sharing between SAP Business Data Cloud and Snowflake without moving or duplicating data. Two integration paths: SAP-provisioned Snowflake or existing Snowflake accounts.

**Read more:** https://docs.snowflake.com/en/release-notes/2026/other/2026-05-04-Snowflake-SAP-zerocopy-integration

### ACCUMULATE Function

New **ACCUMULATE** SQL function for running computations across ordered rows.

**Documentation:** https://docs.snowflake.com/en/sql-reference/functions/accumulate

### Organization Usage: New Network Views (May 5)

## **Semantic Views & Intelligence**

### Semantic View Entity-Level Filters (GA - May 5)

Define facts or dimensions as **filters** in semantic views by specifying `LABELS = (FILTER)`. Filters resolve to BOOLEAN values and can be used as conditions in WHERE clauses, enabling more expressive and governed semantic models.

**Release Notes:** https://docs.snowflake.com/en/release-notes/2026/other/2026-05-05-semantic-views-entity-filters
