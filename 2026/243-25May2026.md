## **Tim's Corner: Summit Week Countdown - AI Function Studio, Iceberg Writes GA, and Batch Search**

Welcome to issue 243! **Snowflake Summit 2026 is ONE WEEK away** - I'll be speaking on NiFi and Agents in San Francisco June 2. This week Snowflake shipped a wave of GA releases leading into Summit. **Cortex AI Function Studio** entered public preview - create, evaluate, and optimize production-ready AI Functions with automated prompt engineering and model selection. **Iceberg table writes via external query engines** went GA through Horizon Catalog - read AND write to Snowflake-managed Iceberg v2/v3 tables from Spark or any Iceberg REST engine. **Batch Cortex Search** went GA with the CORTEX_SEARCH_BATCH table function for millions of fuzzy-match queries in a single SQL statement. **Storage lifecycle policies for dynamic tables** went GA. **dbt Projects on Snowflake** got enhanced DAG visualization with column-level lineage. **CREATE OR ALTER SEMANTIC VIEW** entered preview for declarative semantic view management. The dynamic tables documentation got a full **30-page rewrite**. **dbt Fusion** is now available on Snowflake. And **MCP now connects GitHub Copilot in VS Code to Snowflake Cortex Agents**. OpenFlow keeps expanding with SQL Server CDC, Amazon Kinesis streaming, and more. See you at Summit!
