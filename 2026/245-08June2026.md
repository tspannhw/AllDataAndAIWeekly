## 11. Snowflake Horizon Context & Catalog Enhancements {#horizon-context}

### Overview

**Horizon Context** is a new capability inside Snowflake Horizon Catalog that delivers a governed semantic foundation — ensuring every person, tool, and AI agent operates from the same version of the truth.

**Press release:** `https://www.snowflake.com/en/news/press-releases/snowflake-advances-trusted-ai-with-snowflake-horizon-catalog-centralizing-governance-context-and-security-across-the-enterprise`

**Blog:** `https://www.snowflake.com/en/blog/horizon-context-governed-context`

### The Problem Horizon Context Solves

> *"An AI agent might recommend increasing prices based on revenue data, but if revenue is defined or calculated in different ways across systems, that recommendation can lead to misinformed decisions."*

Traditional semantic layers are separate from the data itself. Horizon Context puts context **directly alongside the data** where it is governed and maintained.

### Three-Part Architecture: Collect → Enrich → Activate

#### 1. Collect — Trusted Business Context

Gather business logic fragmented across SQL, BI dashboards, and agents:

| Wave 1 Connectors (Private Preview) | Description |
|------------------------------------|-------------|
| **PostgreSQL** | Extract schema semantics from Postgres databases |
| **SQL Server** | Extract semantics from Microsoft SQL Server |
| **Tableau** | Import business logic from Tableau workbooks |
| **Power BI** | Import measure definitions from Power BI models |
| **dbt** | Extract semantic models and metric definitions from dbt projects |

Additional connectors in future waves; OSI provides the standard interoperability layer.

#### 2. Enrich — Automatically Maintain Business Context

| Feature | Status | Description |
|---------|--------|-------------|
| **Column-level lineage** | GA | Stitch lineage across systems automatically |
| **AI-generated documentation** | Available | Auto-generate column/table descriptions |
| **Popularity metrics** | Available | Track which tables/columns are most queried |
| **Semantic Studio** | Private Preview | Define shared business logic without SQL |
| **Semantic View Autopilot** | Public Preview | Auto-creates and refines semantic views over time |

**Semantic View Autopilot** also now auto-creates semantic views for data shared across organizations via Snowflake Marketplace, carrying trusted business context into every AI and analytics workflow.

#### 3. Activate — Extend Trusted Context Everywhere

- **CoCo integration:** CoCo pulls rich business context from Horizon Context automatically, delivering more trustworthy responses even for data outside Snowflake

## 14. Cortex AISQL — General Availability {#cortex-aisql}

### Overview

**Cortex AISQL** reached **General Availability** at Summit 2026. Run AI inference directly inside SQL queries, unified across structured and unstructured data.

### Core Functions

| Function | Description |
|---------|-------------|
| `AI_FILTER` | Filter rows using natural language criteria |
| `AI_AGG` | Aggregate unstructured content with AI synthesis |
| `AI_EXTRACT` | Extract structured fields from unstructured text |
| `AI_CLASSIFY` | Classify text or content into categories |

### Example

```sql
SELECT
    o.customer_id,
    o.order_value,
    AI_CLASSIFY(t.transcript_text, ['positive', 'negative', 'neutral']) AS sentiment
FROM orders o
JOIN support_transcripts t ON o.customer_id = t.customer_id
WHERE o.order_date >= '2026-01-01';
```

## 15. Dynamic Tables — General Availability {#dynamic-tables}

### Example: Continuous Sentiment Pipeline

```sql
CREATE OR REPLACE DYNAMIC TABLE customer_sentiment

    WAREHOUSE = analytics_wh

SELECT
    review_id,
    customer_id,

    AI_SENTIMENT(review_text) AS sentiment_score,

```

```sql
CREATE WAREHOUSE my_adaptive_wh
```

## 36. Summary: The Agentic Enterprise Vision {#agentic-vision}

### Snowflake's Four Strategic Pillars at Summit 2026

| Pillar | What It Means | Key Announcements |
|--------|--------------|-------------------|
| **AI-Ready Data** | Governed, clean, semantically rich data | Iceberg V3, Horizon Context, Dynamic Tables GA, AI Redact |
| **Model Flexibility** | Any model without lock-in | SpaceXAI Grok, Cortex Training, all frontier models |
| **Interoperability** | Open, bidirectional connectivity | Iceberg V3 bidirectional, OSI (54 vendors), SAP/Salesforce/Workday/Fabric zero-copy |
| **Agentic Control Plane** | Operating system for enterprise intelligence | CoCo Desktop/SDK/Cloud Agents, CoWork Deep Research/Artifacts/Skills |

### The Agentic Stack (Bottom to Top)

```
┌─────────────────────────────────────────────────────┐
│  AGENTIC SURFACES                                   │
│  CoWork (knowledge workers) ◄──► CoCo (developers) │
└─────────────────────────┬───────────────────────────┘
                          │
┌─────────────────────────▼───────────────────────────┐
│  CONTEXT LAYER                                      │
│  Horizon Context + Cortex Sense + Semantic Studio   │
│  OSI standard (54 vendors) + Natoma MCP gateway     │
└─────────────────────────┬───────────────────────────┘
                          │
┌─────────────────────────▼───────────────────────────┐
│  SECURITY LAYER                                     │
│  Agent Identity + AI Security Posture Management    │
│  Cortex Guard + Data Exfiltration Policies          │
└─────────────────────────┬───────────────────────────┘
                          │
┌─────────────────────────▼───────────────────────────┐
│  AI INFRASTRUCTURE                                  │
│  Cortex AI (all frontier models + Cortex Training)  │
│  Adaptive Compute + Managed GPU clusters            │
└─────────────────────────┬───────────────────────────┘
                          │
┌─────────────────────────▼───────────────────────────┐
│  DATA FOUNDATION                                    │
│  Apache Iceberg V3 (GA) + Snowflake Storage         │
│  Datastream (Kafka) + Openflow (NiFi) + Postgres    │
│  SAP/Salesforce/Workday zero-copy integrations      │
└─────────────────────────────────────────────────────┘
```

### Key Strategic Takeaways

1. **Data is constant; models change** — Snowflake's durable value is connecting the best AI model *today* to the enterprise data that is always there
2. **Context is the new competitive moat** — Cortex Sense (86% accuracy), Horizon Context, and OSI are bets that semantic context is more defensible than model quality
3. **Security is the #1 barrier, now addressed** — Agent Identity (GA) is the direct response to McKinsey's finding that 2/3 of enterprises cite security as the top blocker
4. **Interoperability is a genuine commitment** — Apache Polaris steering committee membership, real Fabric testing, OSI spec, 54 vendors — these are verifiable
5. **Both audiences** — CoWork for knowledge workers, CoCo for builders — ensuring all 13,900+ customers can access AI value regardless of technical sophistication

### CEO's Framing

> *"The very nature of work is changing. Day-to-day work is about partnering with and guiding intelligent agents, and soon they will be operating across your business continuously, autonomously. This truly is going to be the era of the agentic enterprise."*
> — Sridhar Ramaswamy, CEO, Snowflake

## Appendix A: Glossary

| Term | Definition |
|------|-----------|
| **Agentic Enterprise** | Organization where AI agents work alongside humans continuously and autonomously |
| **CoCo** | Snowflake CoCo — AI coding agent for developers (formerly Cortex Code) |
| **CoWork** | Snowflake CoWork — Personal AI work agent for knowledge workers (formerly Snowflake Intelligence) |
| **Cortex AISQL** | SQL functions for running AI inference directly in SQL queries |
| **Cortex Guard** | ML-driven detection of prompt injection, jailbreaks, and zero-day AI vulnerabilities |
| **Cortex Sense** | Shared runtime context layer providing business definitions to all agents; 86% accuracy |
| **Cortex Training** | Snowflake-managed custom model training on GPUs; 2× efficiency vs. alternatives |
| **Datastream** | Snowflake's managed Kafka-compatible streaming service |
| **Dynamic Tables** | Declarative, auto-refreshing pipeline tables in Snowflake |
| **Horizon Catalog** | Snowflake's data governance and discovery layer, embedding Apache Polaris |
| **Horizon Context** | Extension of Horizon Catalog with Collect/Enrich/Activate for business metadata and semantic context |
| **Iceberg V3** | Latest version of Apache Iceberg with deletion vectors, row lineage, variant type, default values |
| **MCP** | Model Context Protocol — open standard for connecting AI tools to data |
| **Natoma** | Acquired startup providing enterprise MCP gateway with identity verification and audit controls |
| **Openflow** | Snowflake's managed data integration service built on Apache NiFi |
| **OSI** | Open Semantic Interchange — open standard for sharing semantic models; 54 participating vendors |
| **SAP BDC** | SAP Business Data Cloud |
| **Semantic View Autopilot** | AI-powered automatic creation and refinement of semantic views |
| **Semantic Studio** | UI for defining shared business logic without SQL expertise |
| **Select Star** | Acquired metadata intelligence company whose technology powers Horizon Context |
| **ADE-Bench** | Analytics and Data Engineering Benchmark by dbt Labs for evaluating AI coding agents |
| **PEFT** | Parameter-Efficient Fine-Tuning — technique for training large models efficiently |
| **BYOC** | Bring Your Own Cloud — architecture where data plane runs in customer's VPC |
